STOP the agent service (turn it OFF temporarily)
    sudo launchctl bootout system/com.aia.agent

    sudo launchctl disable system/com.aia.agent

ENABLE the agent again (allow autostart)
    sudo launchctl enable system/com.aia.agent

    sudo launchctl bootstrap system /Library/LaunchDaemons/com.aia.agent.plist
