-------------------Steps:------------------------

1) Install python (with needed packages)
    - pip3 install flask

2) Install cloudflared
    - brew install cloudflared (macOS)

3) Make a cloudflared tunnel

    1) cloudflared tunnel login
        - It will open a browser → choose your domain (example: cbphysio.in)

    2) cloudflared tunnel create amdermatology-aesthetics-agent
        - Created tunnel amdermatology-aesthetics-agent with id ab411cc1-2b1b-4333-bc9a-07e7cfdee70a

    3) cloudflared tunnel route dns amdermatology-aesthetics-agent amdermatology-agent.drshehlaendocrinologist.com
        - Output:
            2025-12-03T11:55:16Z INF Added CNAME amdermatology-agent.drshehlaendocrinologist.com which will route to this tunnel tunnelID=ab411cc1-2b1b-4333-bc9a-07e7cfdee70a

    4) Create Tunnel Config File => C:\cloudflared\config.yml (nano ~/.cloudflared/config.yml)
        - past code here

        tunnel: amdermatology-aesthetics-agent
        credentials-file: /Users/draakriti/.cloudflared/ab411cc1-2b1b-4333-bc9a-07e7cfdee70a.json

        ingress:
        - hostname: amdermatology-agent.drshehlaendocrinologist.com
            service: http://127.0.0.1:5000

        - service: http_status:404

4) Run python script
    - python3 auto_capture_agent.py

5) Run cloudflared tunnel
    - cloudflared tunnel run amdermatology-aesthetics-agent




=-------------------------------------- python file (autu_capture_agent.py) autoload (macOS) ------------------------------------

1) brew --prefix

2) ls /opt/homebrew/bin/python3

3) echo 'export PATH="/opt/homebrew/bin:$PATH"' >> ~/.zprofile

4) source ~/.zprofile

5) which python3
    - Output
    /opt/homebrew/bin/python3

6) pip3 install flask requests pillow adb-shell --break-system-packages

7) Make dir and permission

    sudo mkdir -p /usr/local/aia
    sudo cp /Users/draakriti/python_script/auto_capture_agent.py /usr/local/aia/
    sudo chown root:wheel /usr/local/aia/auto_capture_agent.py
    sudo chmod 755 /usr/local/aia/auto_capture_agent.py
    sudo touch /usr/local/aia/auto_capture_agent.log
    sudo chmod 666 /usr/local/aia/*.log


8) nano ~/Library/LaunchDaemons/com.aia.agent.plist (if not create file or save then run this command)
    - command : sudo cp /Users/draakriti/python_script/com.aia.agent.plist /Library/LaunchDaemons

    past this code (com.aia.agent.plist)

    <?xml version="1.0" encoding="UTF-8"?>
    <!DOCTYPE plist PUBLIC "-//Apple Computer//DTD PLIST 1.0//EN"
    "http://www.apple.com/DTDs/PropertyList-1.0.dtd">

    <plist version="1.0">
    <dict>
        <key>Label</key>
        <string>com.aia.agent</string>

        <key>ProgramArguments</key>
        <array>
            <string>/opt/homebrew/bin/python3</string>
            <string>/usr/local/aia/auto_capture_agent.py</string>
        </array>

        <key>EnvironmentVariables</key>
        <dict>
            <key>PATH</key>
            <string>/opt/homebrew/bin:/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin</string>
        </dict>

        <key>WorkingDirectory</key>
        <string>/usr/local/aia</string>

        <key>RunAtLoad</key>
        <true/>

        <key>KeepAlive</key>
        <true/>

        <key>StandardOutPath</key>
        <string>/usr/local/aia/auto_capture_agent.log</string>

        <key>StandardErrorPath</key>
        <string>/usr/local/aia/auto_capture_agent.error.log</string>
    </dict>
    </plist>


8) start service
    - sudo launchctl bootout system/com.aia.agent
    - sudo launchctl bootstrap system /Library/LaunchDaemons/com.aia.agent.plist

9) reload service
    - sudo launchctl unload /Library/LaunchDaemons/com.aia.agent.plist
    - sudo launchctl load /Library/LaunchDaemons/com.aia.agent.plist


-------------------------------------------- cloudflare autoload (macOS)---------------------------------
1) sudo cloudflared service install

2) Modify com.cloudflare.cloudflared.plist
    - sudo nano /Library/LaunchDaemons/com.cloudflare.cloudflared.plist

    <?xml version="1.0" encoding="UTF-8"?>
    <!DOCTYPE plist PUBLIC "-//Apple Computer//DTD PLIST 1.0//EN"
    "http://www.apple.com/DTDs/PropertyList-1.0.dtd">

    <plist version="1.0">
    <dict>
        <key>Label</key>
        <string>com.cloudflare.cloudflared</string>

        <key>ProgramArguments</key>
        <array>
            <string>/opt/homebrew/bin/cloudflared</string>
            <string>--config</string>
            <string>/Users/draakriti/.cloudflared/config.yml</string>
            <string>tunnel</string>
            <string>run</string>
        </array>

        <key>RunAtLoad</key>
        <true/>

        <key>KeepAlive</key>
        <true/>

        <key>StandardOutPath</key>
        <string>/Library/Logs/com.cloudflare.cloudflared.out.log</string>

        <key>StandardErrorPath</key>
        <string>/Library/Logs/com.cloudflare.cloudflared.err.log</string>
    </dict>
    </plist>

3) start service
    - sudo launchctl bootout system/com.cloudflare.cloudflared
    - sudo launchctl enable system/com.cloudflare.cloudflared
    - sudo launchctl bootstrap system /Library/LaunchDaemons/com.cloudflare.cloudflared.plist

----- Needed Command ---------------------
--- For python autoload-------

STOP the agent service (turn it OFF temporarily)
    sudo launchctl bootout system/com.aia.agent

DISABLE the agent (prevent autostart at reboot)
    sudo launchctl disable system/com.aia.agent

ENABLE the agent again (allow autostart)
    sudo launchctl enable system/com.aia.agent

START the agent manually
    sudo launchctl bootstrap system /Library/LaunchDaemons/com.aia.agent.plist

RESTART the agent
    sudo launchctl bootout system/com.aia.agent
    sudo launchctl bootstrap system /Library/LaunchDaemons/com.aia.agent.plist

--- For cloudflared service --------------------------------

DISABLE the agent
    sudo launchctl disable system/com.cloudflare.cloudflared

STOP the agent service
    sudo launchctl bootout system/com.cloudflare.cloudflared

ENABLE the agent again
    sudo launchctl enable system/com.cloudflare.cloudflared
    sudo launchctl bootstrap system /Library/LaunchDaemons/com.cloudflare.cloudflared.plist
